# Liborio: Updated

Liborio provides shared helpers for its dependent mods, including table utilities, entity handling, directions, fluids and prototype construction.

This port updates LuaObject validation, cardinal directions, fluid prototype access and icon defaults for Factorio 2.1.24 or later. It retains the library layout and adopts original Liborio save state. Dependent mods should use the updated dependency and import namespace.

Original project: [liborio](https://mods.factorio.com/mod/liborio) — PixelWhipped, with btarrant listed as the original Mod Portal maintainer.
